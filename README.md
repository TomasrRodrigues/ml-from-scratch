# ml-from-scratch

First-principles implementations of core machine learning algorithms in vectorized Python (NumPy). 

## Getting Started
This repository uses uv for fast, deterministic dependency management.

### 1. Installation 
Clone the repository and sync the virtual environment:
```bash
git clone https://github.com/TomasrRodrigues/ml-from-scratch.git
cd ml-from-scratch
uv sync
```

### 2. Running tests
Run the test suite across all implemented models:
```bash
uv run pytest
```
